# NIGHTSHIFT//OS Milestone 1 ("Jack in") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A launchable Tauri desktop app with a working fake-OS shell (windows, nodes, taskbar, JACK menu, desktop icons, layout persistence) and the usable coding core: TERM, EDIT, FILES, SCAN and SYSOP CMD.

**Architecture:** Rust backend (`src-tauri/`) exposes small, unit-tested modules over Tauri commands: workspace-scoped filesystem, PTY sessions, search and state persistence. The frontend is plain TypeScript: a `kernel` (bus, registry, hotkeys, commands, fuzzy matching), a hand-written window manager, and one folder per app. Apps only talk to Rust through `src/ipc.ts`, and to each other through the bus.

**Tech Stack:** Tauri 2, Rust (portable-pty, ignore, serde_json, dirs), Vite + TypeScript, Vitest + jsdom, xterm.js, CodeMirror 6, marked + DOMPurify.

**Spec:** `docs/superpowers/specs/2026-10-15-nightshift-design.md` (milestone 1)

## Global Constraints

- Linux only (Arch + Hyprland, WebKitGTK 2.52). Run dev with `WEBKIT_DISABLE_DMABUF_RENDERER=1` (NVIDIA + Wayland blank-window workaround).
- Node 20.20, Rust 1.98. Frontend: plain TypeScript, no UI framework.
- Hotkey rule: global hotkeys use Ctrl+Shift or Ctrl+Alt only. Never Super (Hyprland) and never bare Ctrl+letter (readline in TERM).
- Workspace scoping: every fs/search path is workspace-relative; Rust rejects `..`, absolute paths and symlink escapes.
- Destructive actions (delete, overwrite, discard unsaved changes) confirm first via in-world dialogs.
- Failed IPC surfaces as a **SYSTEM FAULT** dialog containing the real error text.
- Config lives in `~/.config/nightshift/`; a corrupt or missing state file means starting with defaults plus a warning, never a crash.
- Disk is tight: `[profile.dev] debug = 0` in Cargo.toml; do not add heavy crates beyond those listed.
- All text inserted into the DOM from files, paths or errors uses `textContent`, never `innerHTML` (except sanitized markdown preview).
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Binary / huge / non-UTF-8 file opened in EDIT** → SYSTEM FAULT naming the reason ("BINARY DATA", "FILE TOO LARGE"); no garbage editor tab. *(Task 2 tests `read_rejects_binary`, `read_rejects_huge`.)*
2. **Symlinks inside the workspace pointing outside, or dangling** → access denied; deleting a symlink removes only the link. *(Task 2 tests.)*
3. **Unsaved changes when closing a tab, closing EDIT, or switching workspace** → asks first; cancelling keeps everything. *(Task 7 test `workspace guard blocks change`; Task 9 tab model + guard wiring.)*
4. **Restoring a layout saved on a bigger screen, or a corrupt/old state file** → windows clamped fully on-screen; garbage state ignored with a warning. *(Task 4 corrupt-state test, Task 6 `clampRect` tests, Task 7 `parseSaved` tests.)*
5. **Closing a TERM window or the shell exiting** → shell process is killed and reaped; pane shows `NO CARRIER`. *(Task 3 tests `eof_fires_when_child_killed`, `echo_round_trip` exit; Task 8 router tests.)*

Also: markdown preview must never execute HTML/JS from a file (Task 9 `renderMarkdown` sanitizer test).

```rust
use serde::Serialize;
use std::fs;
use std::path::{Component, Path, PathBuf};
use std::sync::Mutex;
use std::time::UNIX_EPOCH;
use tauri::State;

pub const MAX_READ_BYTES: u64 = 5 * 1024 * 1024;

#[derive(Default)]
pub struct WorkspaceState(pub Mutex<Option<PathBuf>>);

impl WorkspaceState {
    pub fn root(&self) -> Result<PathBuf, String> {
        self.0
            .lock()
            .unwrap()
            .clone()
            .ok_or_else(|| "NO WORKSPACE: open a folder first (Ctrl+Alt+O)".to_string())
    }
}

#[derive(Serialize, Debug, PartialEq)]
pub struct Entry {
    pub name: String,
    pub path: String,
    pub is_dir: bool,
}

#[derive(Serialize, Debug)]
pub struct Stat {
    pub mtime_ms: u64,
    pub size: u64,
    pub is_dir: bool,
}

/// Resolve a workspace-relative path to an absolute path inside `root`
/// (which must already be canonical). Follows symlinks; rejects escapes.
pub fn resolve(root: &Path, rel: &str) -> Result<PathBuf, String> {
    let rel_path = Path::new(rel);
    for c in rel_path.components() {
        match c {
            Component::Normal(_) | Component::CurDir => {}
            _ => return Err(format!("ACCESS DENIED: illegal path '{rel}'")),
        }
    }
    let joined = root.join(rel_path);
    let mut existing = joined.as_path();
    let mut tail = Vec::new();
    // symlink_metadata so a dangling symlink counts as existing (and then fails to canonicalize)
    while existing.symlink_metadata().is_err() {
        tail.push(existing.file_name().ok_or_else(|| format!("invalid path '{rel}'"))?);
        existing = existing.parent().ok_or_else(|| format!("invalid path '{rel}'"))?;
    }
    let mut real = existing
        .canonicalize()
        .map_err(|e| format!("ACCESS DENIED: '{rel}': {e}"))?;
    for part in tail.iter().rev() {
        real.push(part);
    }
    if !real.starts_with(root) {
        return Err(format!("ACCESS DENIED: '{rel}' is outside the workspace"));
    }
    Ok(real)
}

/// Like `resolve`, but does not follow a symlink in the final component,
/// so delete/rename act on the link itself. Refuses the workspace root.
fn resolve_entry(root: &Path, rel: &str) -> Result<PathBuf, String> {
    let rel_path = Path::new(rel);
    let name = rel_path
        .file_name()
        .ok_or_else(|| format!("ACCESS DENIED: cannot modify '{rel}'"))?;
    let parent = rel_path
        .parent()
        .map(|p| p.to_string_lossy().to_string())
        .unwrap_or_default();
    Ok(resolve(root, &parent)?.join(name))
}

fn rel_of(root: &Path, abs: &Path) -> String {
    abs.strip_prefix(root)
        .unwrap_or(abs)
        .to_string_lossy()
        .replace('\\', "/")
}

pub fn stat_path(p: &Path) -> Result<Stat, String> {
    let m = fs::metadata(p).map_err(|e| format!("{}: {e}", p.display()))?;
    let mtime_ms = m
        .modified()
        .ok()
        .and_then(|t| t.duration_since(UNIX_EPOCH).ok())
        .map(|d| d.as_millis() as u64)
        .unwrap_or(0);
    Ok(Stat { mtime_ms, size: m.len(), is_dir: m.is_dir() })
}

pub fn list_dir(root: &Path, rel: &str) -> Result<Vec<Entry>, String> {
    let dir = resolve(root, rel)?;
    let mut out = Vec::new();
    for item in fs::read_dir(&dir).map_err(|e| format!("{rel}: {e}"))? {
        let item = item.map_err(|e| e.to_string())?;
        let name = item.file_name().to_string_lossy().to_string();
        if name == ".git" {
            continue;
        }
        let is_dir = item.path().is_dir();
        out.push(Entry { path: rel_of(root, &dir.join(&name)), name, is_dir });
    }
    out.sort_by(|a, b| {
        b.is_dir
            .cmp(&a.is_dir)
            .then_with(|| a.name.to_lowercase().cmp(&b.name.to_lowercase()))
    });
    Ok(out)
}

pub fn read_text(root: &Path, rel: &str) -> Result<String, String> {
    let p = resolve(root, rel)?;
    let meta = fs::metadata(&p).map_err(|e| format!("{rel}: {e}"))?;
    if meta.is_dir() {
        return Err(format!("{rel} is a directory"));
    }
    if meta.len() > MAX_READ_BYTES {
        return Err(format!(
            "FILE TOO LARGE: {rel} is {:.1} MB (limit 5 MB)",
            meta.len() as f64 / 1_048_576.0
        ));
    }
    let bytes = fs::read(&p).map_err(|e| format!("{rel}: {e}"))?;
    String::from_utf8(bytes).map_err(|_| format!("BINARY DATA: {rel} is not UTF-8 text"))
}

pub fn write_text(root: &Path, rel: &str, content: &str) -> Result<Stat, String> {
    let p = resolve(root, rel)?;
    if let Some(parent) = p.parent() {
        fs::create_dir_all(parent).map_err(|e| format!("{rel}: {e}"))?;
    }
    fs::write(&p, content).map_err(|e| format!("{rel}: {e}"))?;
    stat_path(&p)
}

pub fn make_dir(root: &Path, rel: &str) -> Result<(), String> {
    fs::create_dir_all(resolve(root, rel)?).map_err(|e| format!("{rel}: {e}"))
}

pub fn rename_path(root: &Path, from: &str, to: &str) -> Result<(), String> {
    let a = resolve_entry(root, from)?;
    let b = resolve_entry(root, to)?;
    if b.symlink_metadata().is_ok() {
        return Err(format!("{to} already exists"));
    }
    fs::rename(&a, &b).map_err(|e| format!("rename {from} → {to}: {e}"))
}

pub fn delete_path(root: &Path, rel: &str) -> Result<(), String> {
    let p = resolve_entry(root, rel)?;
    let meta = p.symlink_metadata().map_err(|e| format!("{rel}: {e}"))?;
    if meta.file_type().is_dir() {
        fs::remove_dir_all(&p)
    } else {
        fs::remove_file(&p)
    }
    .map_err(|e| format!("delete {rel}: {e}"))
}

#[tauri::command]
pub fn ws_open(ws: State<WorkspaceState>, path: String) -> Result<String, String> {
    let p = PathBuf::from(&path)
        .canonicalize()
        .map_err(|e| format!("{path}: {e}"))?;
    if !p.is_dir() {
        return Err(format!("{path} is not a directory"));
    }
    *ws.0.lock().unwrap() = Some(p.clone());
```

```rust
use portable_pty::{native_pty_system, Child, CommandBuilder, MasterPty, PtySize};

pub struct Session {
    pub writer: Box<dyn Write + Send>,
    pub master: Box<dyn MasterPty + Send>,
    pub child: Box<dyn Child + Send + Sync>,
}

#[derive(Default)]
pub struct PtyState {
    sessions: Mutex<HashMap<u32, Session>>,
    next_id: AtomicU32,
}

#[derive(Clone, Serialize)]
struct DataEvent {
    id: u32,
    data: Vec<u8>,
}

#[derive(Clone, Serialize)]
struct ExitEvent {
    id: u32,
    code: Option<u32>,
}

pub fn default_shell() -> String {
    std::env::var("SHELL")
        .ok()
        .filter(|s| !s.is_empty())
        .unwrap_or_else(|| "/bin/bash".into())
}

/// Spawn `shell` in a new PTY. `on_data` gets raw output chunks from a reader
/// thread; `on_eof` runs once when the PTY closes (shell exited or killed).
pub fn spawn_session(
    shell: &str,
    cwd: &Path,
    cols: u16,
    rows: u16,
    on_data: impl Fn(Vec<u8>) + Send + 'static,
    on_eof: impl FnOnce() + Send + 'static,
) -> Result<Session, String> {
    let pair = native_pty_system()
        .openpty(PtySize { rows, cols, pixel_width: 0, pixel_height: 0 })
        .map_err(|e| e.to_string())?;
    let mut cmd = CommandBuilder::new(shell);
    cmd.cwd(cwd);
    cmd.env("TERM", "xterm-256color");
    cmd.env("COLORTERM", "truecolor");
    cmd.env("NIGHTSHIFT", "1");
    let child = pair
        .slave
        .spawn_command(cmd)
        .map_err(|e| format!("cannot start {shell}: {e}"))?;
    drop(pair.slave);
    let mut reader = pair.master.try_clone_reader().map_err(|e| e.to_string())?;
    let writer = pair.master.take_writer().map_err(|e| e.to_string())?;
    std::thread::spawn(move || {
        let mut buf = [0u8; 8192];
        loop {
            match reader.read(&mut buf) {
                Ok(0) | Err(_) => break, // Linux returns EIO when the child side closes
                Ok(n) => on_data(buf[..n].to_vec()),
            }
        }
        on_eof();
    });
    Ok(Session { writer, master: pair.master, child })
}

#[tauri::command]
pub fn pty_spawn(
    app: AppHandle,
    ptys: State<PtyState>,
    ws: State<WorkspaceState>,
    cols: u16,
    rows: u16,
    cwd: Option<String>,
) -> Result<u32, String> {
    let dir: PathBuf = match cwd {
        Some(c) if !c.is_empty() => PathBuf::from(c),
        _ => ws
            .root()
            .ok()
            .or_else(dirs::home_dir)
            .unwrap_or_else(|| PathBuf::from("/")),
    };
    let id = ptys.next_id.fetch_add(1, Ordering::Relaxed) + 1;
    let data_app = app.clone();
    let exit_app = app.clone();
    let session = spawn_session(
        &default_shell(),
        &dir,
        cols.max(2),
        rows.max(2),
        move |data| {
            let _ = data_app.emit("pty-data", DataEvent { id, data });
        },
        move || {
            let state = exit_app.state::<PtyState>();
            let removed = state.sessions.lock().unwrap().remove(&id);
            let code = removed
                .and_then(|mut s| s.child.wait().ok())
                .map(|st| st.exit_code());
            let _ = exit_app.emit("pty-exit", ExitEvent { id, code });
        },
    )?;
    ptys.sessions.lock().unwrap().insert(id, session);
    Ok(id)
}

#[tauri::command]
pub fn pty_write(ptys: State<PtyState>, id: u32, data: String) -> Result<(), String> {
    let mut map = ptys.sessions.lock().unwrap();
    let s = map.get_mut(&id).ok_or_else(|| format!("NO CARRIER: session {id}"))?;
    s.writer.write_all(data.as_bytes()).map_err(|e| e.to_string())?;
    s.writer.flush().map_err(|e| e.to_string())
}

#[tauri::command]
pub fn pty_resize(ptys: State<PtyState>, id: u32, cols: u16, rows: u16) -> Result<(), String> {
    let map = ptys.sessions.lock().unwrap();
    let s = map.get(&id).ok_or_else(|| format!("NO CARRIER: session {id}"))?;
    s.master
        .resize(PtySize { rows: rows.max(2), cols: cols.max(2), pixel_width: 0, pixel_height: 0 })
        .map_err(|e| e.to_string())
}

#[tauri::command]
pub fn pty_kill(ptys: State<PtyState>, id: u32) {
    if let Some(mut s) = ptys.sessions.lock().unwrap().remove(&id) {
        let _ = s.child.kill();
        // reap off-thread so the process never lingers as a zombie
        std::thread::spawn(move || {
            let _ = s.child.wait();
        });
    }
}
```

```rust
pub const HIT_CAP: usize = 500;

#[derive(Serialize, Debug, PartialEq)]
pub struct Hit {
    pub path: String,
    pub line: u32,
    pub text: String,
}

pub fn list_files(root: &Path, cap: usize) -> Vec<String> {
    let mut out = Vec::new();
    let walker = WalkBuilder::new(root)
        .hidden(false)
        .require_git(false)
        .filter_entry(|e| e.file_name() != ".git")
        .build();
    for entry in walker.flatten() {
        if entry.file_type().map(|t| t.is_file()).unwrap_or(false) {
            if let Ok(rel) = entry.path().strip_prefix(root) {
                out.push(rel.to_string_lossy().replace('\\', "/"));
                if out.len() >= cap {
                    break;
                }
            }
        }
    }
    out
}

/// Parse one line of `rg --null --line-number` output: `path\0line:text`.
pub fn parse_rg_line(line: &str) -> Option<Hit> {
    let (path, rest) = line.split_once('\0')?;
    let (num, text) = rest.split_once(':')?;
    Some(Hit {
        path: path.trim_start_matches("./").to_string(),
        line: num.parse().ok()?,
        text: text.trim_end().chars().take(300).collect(),
    })
}

pub fn grep(root: &Path, query: &str) -> Result<Vec<Hit>, String> {
    if query.trim().is_empty() {
        return Ok(vec![]);
    }
    let out = Command::new("rg")
        .current_dir(root)
        .args([
            "--null", "--line-number", "--no-heading", "--color", "never",
            "--fixed-strings", "--smart-case", "--max-count", "20", "--max-columns", "300", "--",
        ])
        .arg(query)
        .arg(".")
        .output()
        .map_err(|e| {
            if e.kind() == std::io::ErrorKind::NotFound {
                "MODULE NOT INSTALLED: ripgrep (pacman -S ripgrep)".to_string()
            } else {
                e.to_string()
            }
        })?;
    match out.status.code() {
        Some(0) | Some(1) => {}
        _ => return Err(String::from_utf8_lossy(&out.stderr).trim().to_string()),
    }
    Ok(String::from_utf8_lossy(&out.stdout)
        .lines()
        .filter_map(parse_rg_line)
        .take(HIT_CAP)
        .collect())
}
```

```rust
    pub warning: Option<String>,

pub fn load_from(path: &Path) -> Loaded {
    let text = match fs::read_to_string(path) {
        Ok(t) => t,
        Err(e) if e.kind() == ErrorKind::NotFound => return Loaded { state: None, warning: None },
        Err(e) => return Loaded { state: None, warning: Some(format!("could not read state: {e}")) },

        Ok(v) => Loaded { state: Some(v), warning: None },
        Err(e) => {

            Loaded {

                warning: Some(format!(

            }
        }
    }

    if let Some(dir) = path.parent() {

    let bytes = serde_json::to_vec_pretty(value).map_err(|e| e.to_string())?;
    fs::write(&tmp, bytes).map_err(|e| e.to_string())?;
    fs::rename(&tmp, path).map_err(|e| e.to_string())
}
```

```ts
type Handler = (payload: any) => void

export interface Bus {
  on(ev: string, h: Handler): () => void
  emit(ev: string, payload?: unknown): void
}

export function createBus(): Bus {
  const map = new Map<string, Set<Handler>>()
  return {
    on(ev, h) {
      if (!map.has(ev)) map.set(ev, new Set())
      map.get(ev)!.add(h)
      return () => { map.get(ev)?.delete(h) }
    },
    emit(ev, payload) {
      for (const h of [...(map.get(ev) ?? [])]) {
        try { h(payload) } catch (e) { console.error(`[bus] ${ev}`, e) }
      }
    },
  }
}

export const bus = createBus()
```

```ts
const BOUNDARY = '/_-. '

/** Subsequence match score; null when `query` is not a subsequence of `text`. */
export function fuzzyScore(query: string, text: string): number | null {
  if (!query) return 0
  const q = query.toLowerCase(), t = text.toLowerCase()
  let score = 0, from = 0, prev = -2
  for (const ch of q) {
    const i = t.indexOf(ch, from)
    if (i === -1) return null
    score += 1
    if (i === prev + 1) score += 5
    if (i === 0 || BOUNDARY.includes(t[i - 1])) score += 3
    prev = i
    from = i + 1
  }
  return score - t.length * 0.01
}

export function fuzzyFilter<T>(items: T[], query: string, key: (t: T) => string, limit = 200): T[] {
  if (!query) return items.slice(0, limit)
  const scored: Array<[number, T]> = []
  for (const it of items) {
    const s = fuzzyScore(query, key(it))
    if (s !== null) scored.push([s, it])
  }
  return scored.sort((a, b) => b[0] - a[0]).slice(0, limit).map(([, it]) => it)
}
```

```ts
export interface Combo { ctrl: boolean; alt: boolean; shift: boolean; meta: boolean; code: string }

type KeyLike = Pick<KeyboardEvent, 'ctrlKey' | 'altKey' | 'shiftKey' | 'metaKey' | 'code'>

const NAMED: Record<string, string> = {
  Left: 'ArrowLeft', Right: 'ArrowRight', Up: 'ArrowUp', Down: 'ArrowDown',
  Space: 'Space', Enter: 'Enter', Esc: 'Escape', Tab: 'Tab',
}

export function parseCombo(s: string): Combo {
  const parts = s.split('+')
  const key = parts.pop()!
  const mods = new Set(parts.map(p => p.toLowerCase()))
  const code = NAMED[key]
    ?? (/^[A-Za-z]$/.test(key) ? `Key${key.toUpperCase()}` : /^\d$/.test(key) ? `Digit${key}` : key)
  return { ctrl: mods.has('ctrl'), alt: mods.has('alt'), shift: mods.has('shift'), meta: mods.has('super') || mods.has('meta'), code }
}

export function matches(ev: KeyLike, c: Combo): boolean {
  return ev.code === c.code && ev.ctrlKey === c.ctrl && ev.altKey === c.alt && ev.shiftKey === c.shift && ev.metaKey === c.meta
}

export function installHotkeys(target: Window, bindings: Array<{ combo: string; run: () => void }>): () => void {
  const parsed = bindings.map(b => ({ combo: parseCombo(b.combo), run: b.run }))
  const onKey = (ev: KeyboardEvent) => {
    for (const b of parsed) {
      if (matches(ev, b.combo)) {
        ev.preventDefault()
        ev.stopPropagation()
        b.run()
        return
      }
    }
  }
  target.addEventListener('keydown', onKey, { capture: true })
  return () => target.removeEventListener('keydown', onKey, { capture: true })
}
```

```ts
import type { Bus } from './bus'
import type { AppManifest, Rect, WinHandle, WindowManagerLike } from './types'

export interface LaunchOpts { rect?: Rect; node?: number; minimized?: boolean }

export function createRegistry(wm: WindowManagerLike, bus: Bus) {
  const apps = new Map<string, AppManifest>()
  return {
    register(m: AppManifest) {
      if (apps.has(m.id)) throw new Error(`duplicate app id ${m.id}`)
      apps.set(m.id, m)
    },
    get(id: string) { return apps.get(id) },
    list(): AppManifest[] { return [...apps.values()] },
    launch(id: string, args?: unknown, opts: LaunchOpts = {}): WinHandle | null {
      const m = apps.get(id)
      if (!m) throw new Error(`unknown app ${id}`)
      if (m.run) { m.run(args); return null }
      if (!m.multi) {
        const existing = wm.findByApp(id)
        if (existing) {
          existing.focus()
          if (args !== undefined) bus.emit(`${id}:args`, args)
          return existing
        }
      }
      const win = wm.create({ appId: id, title: m.name, glyph: m.glyph, size: m.size, ...opts })
      win.setPersist(args ?? null)
      m.open!({ win, bus }, args)
      return win
    },
  }
}

export type Registry = ReturnType<typeof createRegistry>
```

```ts
import type { Rect } from '../kernel/types'

export type SnapDir = 'left' | 'right' | 'up' | 'down'
export const MIN_W = 320
export const MIN_H = 200

export function snapRect(dir: SnapDir, a: Rect): Rect {
  const hw = Math.floor(a.w / 2)
  switch (dir) {
    case 'left': return { x: a.x, y: a.y, w: hw, h: a.h }
    case 'right': return { x: a.x + hw, y: a.y, w: a.w - hw, h: a.h }
    case 'up': return { ...a }
    case 'down': {
      const w = Math.round(a.w * 0.6), h = Math.round(a.h * 0.6)
      return { x: a.x + Math.round((a.w - w) / 2), y: a.y + Math.round((a.h - h) / 2), w, h }
    }
  }
}

export function tileRects(n: number, a: Rect, gap = 6): Rect[] {
  if (n <= 0) return []
  const cols = Math.ceil(Math.sqrt(n)), rows = Math.ceil(n / cols)
  const cw = (a.w - gap * (cols + 1)) / cols
  const ch = (a.h - gap * (rows + 1)) / rows
  return Array.from({ length: n }, (_, i) => {
    const c = i % cols, r = Math.floor(i / cols)
    return { x: Math.round(a.x + gap + c * (cw + gap)), y: Math.round(a.y + gap + r * (ch + gap)), w: Math.round(cw), h: Math.round(ch) }
  })
}

/** Keep a window fully inside the area, within min size. */
export function clampRect(r: Rect, a: Rect): Rect {
  const w = Math.min(Math.max(r.w, MIN_W), a.w)
  const h = Math.min(Math.max(r.h, MIN_H), a.h)
  const x = Math.min(Math.max(r.x, a.x), a.x + a.w - w)
  const y = Math.min(Math.max(r.y, a.y), a.y + a.h - h)
  return { x, y, w, h }
}
```

```ts
import type { Bus } from '../kernel/bus'
import type { CreateOpts, Rect, WinHandle, WindowManagerLike } from '../kernel/types'
import { clampRect, snapRect, tileRects, MIN_H, MIN_W, type SnapDir } from './geometry'

export const NODES = 4

export interface WinState { appId: string; rect: Rect; node: number; minimized: boolean; persist: unknown }
export interface WinInfo { id: number; appId: string; title: string; glyph: string; node: number; minimized: boolean; active: boolean }

interface Win {
  id: number; appId: string; title: string; glyph: string
  el: HTMLElement; body: HTMLElement; nameEl: HTMLElement
  rect: Rect; prevRect: Rect | null; node: number; minimized: boolean; z: number
  persist: unknown
  guards: Array<() => Promise<boolean> | boolean>
  closeCbs: Array<() => void>; resizeCbs: Array<() => void>; focusCbs: Array<() => void>
  handle: WinHandle
}

const FRAME = `<div class="win-title"><span class="win-glyph"></span><span class="win-name"></span><span class="win-btns"><button data-act="min" title="Minimize">_</button><button data-act="max" title="Maximize">□</button><button data-act="close" title="Close">×</button></span></div><div class="win-body"></div><div class="win-resize"></div>`

export class WindowManager implements WindowManagerLike {
  node = 1
  private wins = new Map<number, Win>()
  private nextId = 1
  private topZ = 10
  private activeId: number | null = null

  constructor(private layer: HTMLElement, private bus: Bus) {}

  area(): Rect {
    return { x: 0, y: 0, w: this.layer.clientWidth || window.innerWidth, h: this.layer.clientHeight || window.innerHeight }
  }

  create(o: CreateOpts): WinHandle {
    const id = this.nextId++
    const el = document.createElement('div')
    el.className = 'win'
    el.dataset.app = o.appId
    el.dataset.id = String(id)
    el.innerHTML = FRAME
    const nameEl = el.querySelector('.win-name') as HTMLElement
    ;(el.querySelector('.win-glyph') as HTMLElement).textContent = o.glyph
    nameEl.textContent = o.title
    const cascade = (this.wins.size % 8) * 28
    const size = o.size ?? { w: 720, h: 460 }
    const w: Win = {
      id, appId: o.appId, title: o.title, glyph: o.glyph,
      el, body: el.querySelector('.win-body') as HTMLElement, nameEl,
      rect: clampRect(o.rect ?? { x: 60 + cascade, y: 40 + cascade, ...size }, this.area()),
      prevRect: null, node: o.node ?? this.node, minimized: !!o.minimized, z: 0, persist: null,
      guards: [], closeCbs: [], resizeCbs: [], focusCbs: [],
      handle: undefined as unknown as WinHandle,
    }
    w.handle = this.makeHandle(w)
    this.wins.set(id, w)
    this.layer.append(el)
    this.applyRect(w)
    this.wire(w)
    if (!w.minimized && w.node === this.node) this.focus(id)
    else { w.z = ++this.topZ; el.style.zIndex = String(w.z); this.applyVisibility(w); this.changed() }
    return w.handle
  }

  findByApp(appId: string): WinHandle | undefined {
    for (const w of this.wins.values()) if (w.appId === appId) return w.handle
    return undefined
  }

  focused(): WinHandle | undefined {
    return this.activeId === null ? undefined : this.wins.get(this.activeId)?.handle
  }

  focus(id: number) {
    const w = this.wins.get(id)
    if (!w) return
    if (w.node !== this.node) { this.node = w.node; this.wins.forEach(o => this.applyVisibility(o)) }
    w.minimized = false
    w.z = ++this.topZ
    w.el.style.zIndex = String(w.z)
    this.activeId = id
    for (const o of this.wins.values()) o.el.classList.toggle('active', o.id === id)
    this.applyVisibility(w)
    w.focusCbs.forEach(cb => cb())
    this.changed()
  }

  async close(id: number): Promise<boolean> {
    const w = this.wins.get(id)
    if (!w) return false
    for (const g of w.guards) if (!(await g())) return false
    for (const cb of w.closeCbs) { try { cb() } catch (e) { console.error('[wm] onClose', e) } }
    w.el.remove()
    this.wins.delete(id)
    if (this.activeId === id) this.focusTop()
    this.changed()
    return true
  }

  minimize(id: number) {
    const w = this.wins.get(id)
    if (!w) return
    w.minimized = true
    this.applyVisibility(w)
    if (this.activeId === id) this.focusTop()
    this.changed()
  }

  toggleMax(id: number) {
    const w = this.wins.get(id)
    if (!w) return
    if (w.prevRect) { w.rect = w.prevRect; w.prevRect = null }
    else { w.prevRect = w.rect; w.rect = this.area() }
    this.applyRect(w)
    this.changed()
  }

  snap(id: number, dir: SnapDir) {
    const w = this.wins.get(id)
    if (!w) return
    w.prevRect = w.prevRect ?? w.rect
    w.rect = snapRect(dir, this.area())
    this.applyRect(w)
    this.changed()
  }

  tileAll() {
    const vis = [...this.wins.values()].filter(w => w.node === this.node && !w.minimized).sort((a, b) => a.id - b.id)
    tileRects(vis.length, this.area()).forEach((r, i) => { vis[i].rect = r; vis[i].prevRect = null; this.applyRect(vis[i]) })
    this.changed()
  }

  setNode(n: number) {
    this.node = n
    this.wins.forEach(w => this.applyVisibility(w))
    this.focusTop()
    this.changed()
  }

  moveToNode(id: number, n: number) {
    const w = this.wins.get(id)
    if (!w) return
    w.node = n
    this.applyVisibility(w)
    if (this.activeId === id && n !== this.node) this.focusTop()
    this.changed()
  }

  /** re-clamp every window, e.g. after the app window shrinks */
  reflow() {
    const a = this.area()
    this.wins.forEach(w => { w.rect = clampRect(w.rect, a); this.applyRect(w) })
    this.changed()
  }

  list(): WinInfo[] {
    return [...this.wins.values()].sort((a, b) => a.id - b.id).map(w => ({
      id: w.id, appId: w.appId, title: w.title, glyph: w.glyph, node: w.node, minimized: w.minimized, active: w.id === this.activeId,
    }))
  }

  serialize(): WinState[] {
    return [...this.wins.values()].sort((a, b) => a.z - b.z).map(w => ({
      appId: w.appId, rect: { ...w.rect }, node: w.node, minimized: w.minimized, persist: w.persist,
    }))
  }

  private focusTop() {
    const top = [...this.wins.values()].filter(w => w.node === this.node && !w.minimized).sort((a, b) => b.z - a.z)[0]
    if (top) this.focus(top.id)
    else { this.activeId = null; this.wins.forEach(w => w.el.classList.remove('active')) }
  }

  private makeHandle(w: Win): WinHandle {
    return {
      id: w.id, appId: w.appId, body: w.body,
      setTitle: t => { w.title = t; w.nameEl.textContent = t; this.changed() },
      setPersist: a => { w.persist = a; this.bus.emit('persist:changed') },
      focus: () => this.focus(w.id),
      close: () => this.close(w.id),
      onClose: cb => { w.closeCbs.push(cb) },
      onResize: cb => { w.resizeCbs.push(cb) },
      onFocus: cb => { w.focusCbs.push(cb) },
      beforeClose: g => { w.guards.push(g) },
    }
  }

  private wire(w: Win) {
    const title = w.el.querySelector('.win-title') as HTMLElement
    const grip = w.el.querySelector('.win-resize') as HTMLElement
    w.el.addEventListener('pointerdown', () => { if (this.activeId !== w.id) this.focus(w.id) }, true)
    title.addEventListener('dblclick', e => { if (!(e.target as HTMLElement).closest('button')) this.toggleMax(w.id) })
    title.addEventListener('pointerdown', e => {
      if (e.button !== 0 || (e.target as HTMLElement).closest('button')) return
      this.drag(e, title, w, (dx, dy, s) => { w.prevRect = null; w.rect = { ...s, x: s.x + dx, y: s.y + dy } })
    })
    grip.addEventListener('pointerdown', e => {
      if (e.button !== 0) return
      e.stopPropagation()
      this.drag(e, grip, w, (dx, dy, s) => { w.prevRect = null; w.rect = { ...s, w: Math.max(MIN_W, s.w + dx), h: Math.max(MIN_H, s.h + dy) } })
    })
    w.el.querySelector('.win-btns')!.addEventListener('click', e => {
      const act = (e.target as HTMLElement).closest('button')?.dataset.act
      if (act === 'min') this.minimize(w.id)
      else if (act === 'max') this.toggleMax(w.id)
      else if (act === 'close') void this.close(w.id)
    })
    if (typeof ResizeObserver !== 'undefined') new ResizeObserver(() => w.resizeCbs.forEach(cb => cb())).observe(w.body)
  }

  private drag(e: PointerEvent, target: HTMLElement, w: Win, move: (dx: number, dy: number, start: Rect) => void) {
    const sx = e.clientX, sy = e.clientY, start = { ...w.rect }
    target.setPointerCapture?.(e.pointerId)
    document.body.classList.add('dragging')
    const onMove = (ev: PointerEvent) => { move(ev.clientX - sx, ev.clientY - sy, start); this.applyRect(w) }
    const onUp = () => {
      target.removeEventListener('pointermove', onMove)
      target.removeEventListener('pointerup', onUp)
      document.body.classList.remove('dragging')
      w.rect = clampRect(w.rect, this.area())
      this.applyRect(w)
      this.changed()
    }
    target.addEventListener('pointermove', onMove)
    target.addEventListener('pointerup', onUp)
  }

  private applyRect(w: Win) {
    Object.assign(w.el.style, { left: `${w.rect.x}px`, top: `${w.rect.y}px`, width: `${w.rect.w}px`, height: `${w.rect.h}px` })
  }

  private applyVisibility(w: Win) {
    w.el.style.display = w.node === this.node && !w.minimized ? '' : 'none'
  }

  private changed() { this.bus.emit('wm:changed') }
}
```

```ts
interface ModalOpts { title: string; message: string; danger?: boolean }
type Val<T> = T | (() => T)
interface ModalSpec<T> { buttons: Array<[act: string, label: string, value: Val<T>]>; cancel: T; enter?: () => T; focus?: HTMLElement }

const resolveVal = <T,>(v: Val<T>): T => (typeof v === 'function' ? (v as () => T)() : v)

function modal<T>(o: ModalOpts, build: (box: HTMLElement) => ModalSpec<T>): Promise<T> {
  return new Promise(resolve => {
    const backdrop = document.createElement('div')
    backdrop.className = 'modal-backdrop'
    const box = document.createElement('div')
    box.className = 'modal' + (o.danger ? ' danger' : '')
    const title = document.createElement('div'); title.className = 'modal-title'; title.textContent = o.title
    const msg = document.createElement('div'); msg.className = 'modal-msg'; msg.textContent = o.message
    box.append(title, msg)
    const spec = build(box)
    const row = document.createElement('div'); row.className = 'modal-btns'
    const done = (v: T) => { backdrop.remove(); resolve(v) }
    for (const [act, label, value] of spec.buttons) {
      const b = document.createElement('button'); b.dataset.act = act; b.textContent = label
      b.onclick = () => done(resolveVal(value))
      row.append(b)
    }
    box.append(row)
    backdrop.append(box)
    backdrop.addEventListener('keydown', e => {
      if (e.key === 'Escape') { e.preventDefault(); e.stopPropagation(); done(spec.cancel) }
      else if (e.key === 'Enter' && spec.enter) { e.preventDefault(); e.stopPropagation(); done(spec.enter()) }
    })
    document.body.append(backdrop)
    ;(spec.focus ?? (row.querySelector('[data-act=ok]') as HTMLElement | null))?.focus()
  })
}

export function confirmDialog(o: ModalOpts & { ok?: string; cancel?: string }): Promise<boolean> {
  return modal<boolean>(o, () => ({
    buttons: [['cancel', `[ ${o.cancel ?? 'CANCEL'} ]`, false], ['ok', `[ ${o.ok ?? 'OK'} ]`, true]],
    cancel: false,
    enter: () => true,
  }))
}

export function promptDialog(o: ModalOpts & { value?: string }): Promise<string | null> {
  const input = document.createElement('input')
  input.value = o.value ?? ''
  input.spellcheck = false
  const read = () => input.value.trim() || null
  return modal<string | null>(o, box => {
    box.append(input)
    setTimeout(() => input.select())
    return { buttons: [['cancel', '[ CANCEL ]', null], ['ok', '[ OK ]', read]], cancel: null, enter: read, focus: input }
  })
}

export function fault(err: unknown): void {
  const message = err instanceof Error ? err.message : String(err)
  console.error('[SYSTEM FAULT]', err)
  void modal<string>({ title: '▓ SYSTEM FAULT ▓', message, danger: true }, () => ({
    buttons: [['copy', '[ COPY ]', 'copy'], ['ok', '[ OK ]', 'ok']],
    cancel: 'ok',
    enter: () => 'ok',
  })).then(v => { if (v === 'copy') void navigator.clipboard?.writeText(message).catch(() => {}) })
}

export function toast(msg: string, ms = 3500): void {
  let tray = document.querySelector('.toasts') as HTMLElement | null
  if (!tray) { tray = document.createElement('div'); tray.className = 'toasts'; document.body.append(tray) }
  const t = document.createElement('div'); t.className = 'toast'; t.textContent = msg
  tray.append(t)
  setTimeout(() => t.remove(), ms)
}

export async function guarded<T>(p: Promise<T>): Promise<T | undefined> {
  try { return await p } catch (e) { fault(e); return undefined }
}
```

```ts
import { ipc } from './ipc'
import type { Bus } from './kernel/bus'
import type { Registry } from './kernel/registry'
import type { Rect } from './kernel/types'
import { toast } from './system/dialog'
import { workspace } from './workspace'
import { NODES, type WindowManager, type WinState } from './wm/wm'

export interface SavedState { version: 1; workspace: string | null; node: number; windows: WinState[] }

export function buildSaved(windows: WinState[], node: number, ws: string | null): SavedState {
  return { version: 1, workspace: ws, node, windows }
}

const clampNode = (n: unknown) => (Number.isInteger(n) && (n as number) >= 1 && (n as number) <= NODES ? (n as number) : 1)
const isRect = (v: any): v is Rect => !!v && ['x', 'y', 'w', 'h'].every(k => Number.isFinite(v[k]))

export function parseSaved(raw: unknown): SavedState | null {
  if (!raw || typeof raw !== 'object') return null
  const r = raw as Record<string, any>
  if (r.version !== 1) return null
  const windows: WinState[] = (Array.isArray(r.windows) ? r.windows : [])
    .filter((w: any) => w && typeof w.appId === 'string' && isRect(w.rect))
    .map((w: any) => ({ appId: w.appId, rect: { x: w.rect.x, y: w.rect.y, w: w.rect.w, h: w.rect.h }, node: clampNode(w.node), minimized: !!w.minimized, persist: w.persist ?? null }))
  return { version: 1, workspace: typeof r.workspace === 'string' ? r.workspace : null, node: clampNode(r.node), windows }
}

export async function restore(registry: Registry, wm: WindowManager): Promise<void> {
  const { state, warning } = await ipc.stateLoad()
  if (warning) toast(warning, 8000)
  const saved = parseSaved(state)
  if (!saved) return
  if (saved.workspace) {
    try { await workspace.set(saved.workspace) } catch { toast(`WORKSPACE LOST: ${saved.workspace}`) }
  }
  for (const w of saved.windows) {
    try { registry.launch(w.appId, w.persist ?? undefined, { rect: w.rect, node: w.node, minimized: w.minimized }) }
    catch (e) { console.warn('[restore]', w.appId, e) }
  }
  wm.setNode(saved.node)
}

export function startPersistence(wm: WindowManager, bus: Bus): void {
  let timer: number | undefined
  const save = () => {
    clearTimeout(timer)
    timer = window.setTimeout(() => {
      ipc.stateSave(buildSaved(wm.serialize(), wm.node, workspace.root)).catch(e => console.warn('[persist]', e))
    }, 800)
  }
  for (const ev of ['wm:changed', 'persist:changed', 'workspace:changed']) bus.on(ev, save)
}
```

```ts
type Sink = (d: Uint8Array) => void

/** Routes pty-data events to terminals; buffers chunks for ids not attached yet. */
export function createPtyRouter() {
  const sinks = new Map<number, Sink>()
  const pending = new Map<number, Uint8Array[]>()
  const closed = new Set<number>()
  return {
    route(id: number, d: Uint8Array) {
      const s = sinks.get(id)
      if (s) s(d)
      else if (!closed.has(id)) { const p = pending.get(id) ?? []; p.push(d); pending.set(id, p) }
    },
    attach(id: number, sink: Sink) {
      sinks.set(id, sink)
      for (const d of pending.get(id) ?? []) sink(d)
      pending.delete(id)
    },
    detach(id: number) { sinks.delete(id); pending.delete(id); closed.add(id) },
    pendingCount() { return pending.size },
  }
}
```

```ts
async function mountTerminal({ win }: AppContext, args: TermArgs) {
  wire()
  win.setPersist({ cwd: args.cwd })
  const host = document.createElement('div')
  host.className = 'term-host'
  const find = document.createElement('div')
  find.className = 'term-find hidden'
  const findInput = document.createElement('input')
  findInput.placeholder = 'find in scrollback'
  find.append(findInput)
  win.body.append(host, find)

  const xterm = new Terminal({ fontFamily: MONO, fontSize: 14, cursorBlink: true, scrollback: 5000, allowProposedApi: true, theme: xtermTheme })
  const fit = new FitAddon()
  const search = new SearchAddon()
  xterm.loadAddon(fit)
  xterm.loadAddon(search)
  xterm.loadAddon(new WebLinksAddon((_e, uri) => { void openUrl(uri) }))
  xterm.open(host)
  fit.fit()

  let id: number | null = null
  const connect = async () => {
    try { id = await ipc.ptySpawn(xterm.cols, xterm.rows, args.cwd) } catch (e) { fault(e); return }
    const myId = id
    exits.set(myId, code => {
      exits.delete(myId); router.detach(myId)
      if (id === myId) id = null
      xterm.write(`\r\n\x1b[31m[NO CARRIER (exit ${code ?? '?'})]\x1b[0m press R to reconnect\r\n`)
    })
    router.attach(myId, d => xterm.write(d))
    if (args.command) void ipc.ptyWrite(myId, args.command + '\n')
  }

  xterm.onData(d => {
    if (id !== null) void ipc.ptyWrite(id, d).catch(() => {})
    else if (d === 'r' || d === 'R') { xterm.reset(); void connect() }
  })
  xterm.attachCustomKeyEventHandler(ev => {
    if (ev.type !== 'keydown' || !ev.ctrlKey || !ev.shiftKey) return true
    if (ev.code === 'KeyF') { find.classList.remove('hidden'); findInput.select(); findInput.focus(); return false }
    if (ev.code === 'KeyC') { const s = xterm.getSelection(); if (s) void writeText(s); return false }
    if (ev.code === 'KeyV') { void readText().then(t => { if (t && id !== null) void ipc.ptyWrite(id, t) }).catch(() => {}); return false }
    return true
  })
  findInput.addEventListener('keydown', e => {
    if (e.key === 'Enter') { e.preventDefault(); (e.shiftKey ? search.findPrevious : search.findNext).call(search, findInput.value) }
    else if (e.key === 'Escape') { find.classList.add('hidden'); search.clearDecorations(); xterm.focus() }
  })

  win.onResize(() => {
    try { fit.fit() } catch { return }
    if (id !== null) void ipc.ptyResize(id, xterm.cols, xterm.rows).catch(() => {})
  })
  win.onFocus(() => xterm.focus())
  win.onClose(() => {
    if (id !== null) { const dead = id; id = null; exits.delete(dead); router.detach(dead); void ipc.ptyKill(dead).catch(() => {}) }
    xterm.dispose()
  })

  await connect()
  xterm.focus()
}
```

```ts
export class TabList {
  paths: string[] = []
  private active = -1

  open(path: string): number {
    let i = this.paths.indexOf(path)
    if (i === -1) { this.paths.push(path); i = this.paths.length - 1 }
    this.active = i
    return i
  }

  /** remove a tab; returns the path that should now be shown */
  close(path: string): string | null {
    const i = this.paths.indexOf(path)
    if (i === -1) return this.current()
    this.paths.splice(i, 1)
    if (!this.paths.length) { this.active = -1; return null }
    if (i < this.active) this.active--
    else if (i === this.active) this.active = Math.min(i, this.paths.length - 1)
    return this.current()
  }

  current(): string | null { return this.active >= 0 ? this.paths[this.active] : null }
}
```

```ts
import type { Extension } from '@codemirror/state'

export type LangKey = 'ts' | 'tsx' | 'js' | 'jsx' | 'rust' | 'python' | 'html' | 'css' | 'json' | 'markdown' | 'yaml' | 'toml' | 'shell'

const EXT: Record<string, LangKey> = {
  ts: 'ts', mts: 'ts', cts: 'ts', tsx: 'tsx', js: 'js', mjs: 'js', cjs: 'js', jsx: 'jsx',
  rs: 'rust', py: 'python', html: 'html', htm: 'html', css: 'css', json: 'json',
  md: 'markdown', markdown: 'markdown', yml: 'yaml', yaml: 'yaml', toml: 'toml', sh: 'shell', bash: 'shell', zsh: 'shell',
}

export function langKey(path: string): LangKey | null {
  const base = path.split('/').pop() ?? ''
  if (/^\.(bash|zsh)rc$|^\.(bash_)?profile$/.test(base)) return 'shell'
  const dot = base.lastIndexOf('.')
  if (dot <= 0) return null
  return EXT[base.slice(dot + 1).toLowerCase()] ?? null
}

export async function loadLanguage(key: LangKey | null): Promise<Extension | null> {
  switch (key) {
    case 'ts': return (await import('@codemirror/lang-javascript')).javascript({ typescript: true })
    case 'tsx': return (await import('@codemirror/lang-javascript')).javascript({ typescript: true, jsx: true })
    case 'js': return (await import('@codemirror/lang-javascript')).javascript()
    case 'jsx': return (await import('@codemirror/lang-javascript')).javascript({ jsx: true })
    case 'rust': return (await import('@codemirror/lang-rust')).rust()
    case 'python': return (await import('@codemirror/lang-python')).python()
    case 'html': return (await import('@codemirror/lang-html')).html()
    case 'css': return (await import('@codemirror/lang-css')).css()
    case 'json': return (await import('@codemirror/lang-json')).json()
    case 'markdown': return (await import('@codemirror/lang-markdown')).markdown()
    case 'yaml': return (await import('@codemirror/lang-yaml')).yaml()
    case 'toml': {
      const [{ StreamLanguage }, { toml }] = await Promise.all([import('@codemirror/language'), import('@codemirror/legacy-modes/mode/toml')])
      return StreamLanguage.define(toml)
    }
    case 'shell': {
      const [{ StreamLanguage }, { shell }] = await Promise.all([import('@codemirror/language'), import('@codemirror/legacy-modes/mode/shell')])
      return StreamLanguage.define(shell)
    }
    default: return null
  }
}
```

```ts
import { ipc } from '../../ipc'
import { workspace } from '../../workspace'

export function createTree(host: HTMLElement, onOpen: (path: string) => void) {
  const expanded = new Set<string>()

  async function renderDir(container: HTMLElement, rel: string, depth: number) {
    let entries
    try { entries = await ipc.list(rel) } catch (e) { container.textContent = `  ${String(e)}`; return }
    container.replaceChildren()
    for (const e of entries) {
      const row = document.createElement('div')
      row.className = 'tree-row' + (e.is_dir ? ' dir' : '')
      row.style.paddingLeft = `${6 + depth * 12}px`
      row.title = e.path
      const label = () => { row.textContent = (e.is_dir ? (expanded.has(e.path) ? '▾ ' : '▸ ') : '  ') + e.name }
      label()
      container.append(row)
      if (e.is_dir) {
        const kids = document.createElement('div')
        container.append(kids)
        if (expanded.has(e.path)) void renderDir(kids, e.path, depth + 1)
        row.onclick = () => {
          if (expanded.has(e.path)) { expanded.delete(e.path); kids.replaceChildren() }
          else { expanded.add(e.path); void renderDir(kids, e.path, depth + 1) }
          label()
        }
      } else {
        row.onclick = () => onOpen(e.path)
      }
    }
  }

  async function refresh() {
    if (!workspace.root) { host.textContent = '  NO WORKSPACE'; return }
    await renderDir(host, '', 0)
  }

  return { refresh, reset() { expanded.clear(); void refresh() } }
}
```

```ts
import { indentWithTab } from '@codemirror/commands'
import { EditorState, type Extension } from '@codemirror/state'
import { EditorView, keymap } from '@codemirror/view'
import { openUrl } from '@tauri-apps/plugin-opener'
import { basicSetup } from 'codemirror'
import { ipc } from '../../ipc'
import type { AppContext, AppManifest } from '../../kernel/types'
import { confirmDialog, fault } from '../../system/dialog'
import { workspace } from '../../workspace'
import { phosphorTheme } from './cmtheme'
import { langKey, loadLanguage, type LangKey } from './langs'
import { renderMarkdown } from './preview'
import { TabList } from './tabs'
import { createTree } from './tree'

export interface EditArgs { files?: string[]; active?: string | null; open?: { path: string; line?: number } }

interface Doc { state: EditorState; dirty: boolean; mtime: number; lang: LangKey | null }

export const edit: AppManifest = {
  id: 'edit', name: 'EDIT', glyph: '{}', category: 'core', multi: false, hotkey: 'Ctrl+Alt+E', size: { w: 1000, h: 640 },
  open: (ctx, args) => mountEditor(ctx, (args ?? {}) as EditArgs),
}

const EMPTY = () => EditorState.create({ doc: '', extensions: [phosphorTheme, EditorView.editable.of(false)] })

function mountEditor({ win, bus }: AppContext, initial: EditArgs) {
  win.body.classList.add('edit')
  win.body.innerHTML = `<div class="edit-tree"></div><div class="edit-main"><div class="edit-tabs"></div><div class="edit-panes"><div class="edit-cm"></div><div class="edit-preview hidden"></div></div><div class="edit-status"></div></div>`
  const $ = (s: string) => win.body.querySelector(s) as HTMLElement
  const docs = new Map<string, Doc>()
  const tabs = new TabList()
  let current: string | null = null
  let previewOn = false
  let previewTimer: number | undefined
  let statusMsg = ''

  const view = new EditorView({ parent: $('.edit-cm'), state: EMPTY() })
  const tree = createTree($('.edit-tree'), p => void openPath(p))
  void tree.refresh()

  const dirtyCount = () => [...docs.values()].filter(d => d.dirty).length

  function extensions(path: string, lang: Extension | null): Extension[] {
    return [
      basicSetup,
      keymap.of([{ key: 'Mod-s', preventDefault: true, run: () => { void save(); return true } }, indentWithTab]),
      phosphorTheme,
      lang ?? [],
      EditorView.updateListener.of(u => {
        if (u.docChanged) {
          const d = docs.get(path)
          if (d && !d.dirty) { d.dirty = true; renderTabs() }
          schedulePreview()
        }
        if (u.docChanged || u.selectionSet) renderStatus()
      }),
    ]
  }

  async function openPath(path: string, line?: number, quiet = false) {
    if (!docs.has(path)) {
      let text: string, mtime: number
      try {
        const [t, st] = await Promise.all([ipc.read(path), ipc.stat(path)])
        text = t; mtime = st.mtime_ms
      } catch (e) { if (!quiet) fault(e); return }
      const key = langKey(path)
      const lang = await loadLanguage(key).catch(() => null)
      docs.set(path, { state: EditorState.create({ doc: text, extensions: extensions(path, lang) }), dirty: false, mtime, lang: key })
    }
    tabs.open(path)
    show(path)
    if (line) gotoLine(line)
    persist()
  }

  function show(path: string | null) {
    if (current && docs.has(current)) docs.get(current)!.state = view.state
    current = path
    view.setState(path ? docs.get(path)!.state : EMPTY())
    if (!path || docs.get(path)!.lang !== 'markdown') setPreview(false)
    else if (previewOn) void renderPreview()
    statusMsg = ''
    renderTabs(); renderStatus()
    win.setTitle(path ? `EDIT ─ ${path}` : 'EDIT')
    view.focus()
  }

  function gotoLine(line: number) {
    const l = view.state.doc.line(Math.min(Math.max(1, line), view.state.doc.lines))
    view.dispatch({ selection: { anchor: l.from }, effects: EditorView.scrollIntoView(l.from, { y: 'center' }) })
  }

  async function save() {
    if (!current) return
    const path = current
    const d = docs.get(path)!
    try {
      const st = await ipc.stat(path).catch(() => null)
      if (st && st.mtime_ms !== d.mtime) {
        const ok = await confirmDialog({ title: 'SHARD CONFLICT', message: `${path} changed on disk since you opened it.\nOverwrite it with your version?`, ok: 'OVERWRITE', danger: true })
        if (!ok) return
      }
      const out = await ipc.write(path, (path === current ? view.state : d.state).doc.toString())
      d.mtime = out.mtime_ms
      d.dirty = false
      statusMsg = 'SAVED'
      renderTabs(); renderStatus()
      bus.emit('fs:changed', path)
    } catch (e) { fault(e) }
  }

  let checking = false
  async function checkExternal() {
    if (!current || checking) return
    checking = true
    const path = current
    const d = docs.get(path)!
    try {
      const st = await ipc.stat(path).catch(() => null)
      if (!st || st.mtime_ms === d.mtime) return
      d.mtime = st.mtime_ms
      if (d.dirty) {
        const reload = await confirmDialog({ title: 'EXTERNAL WRITE DETECTED', message: `${path} changed on disk.\nReload it and discard your unsaved edits?`, ok: 'RELOAD', cancel: 'KEEP MINE', danger: true })
        if (!reload) return
      }
      const text = await ipc.read(path)
      if (current !== path) return
      view.dispatch({ changes: { from: 0, to: view.state.doc.length, insert: text } })
      d.dirty = false
      statusMsg = 'RELOADED'
      renderTabs(); renderStatus()
    } catch (e) { fault(e) } finally { checking = false }
  }

  async function closeTab(path: string) {
    const d = docs.get(path)
    if (!d) return
    if (d.dirty && !(await confirmDialog({ title: 'UNSAVED SHARD', message: `Close ${path} without saving?`, ok: 'DISCARD', danger: true }))) return
    if (current === path) current = null
    docs.delete(path)
    show(tabs.close(path))
    persist()
  }

  function renderTabs() {
    const bar = $('.edit-tabs')
    bar.replaceChildren(...tabs.paths.map(p => {
      const tab = document.createElement('div')
      tab.className = 'tab' + (p === current ? ' active' : '') + (docs.get(p)?.dirty ? ' dirty' : '')
      tab.title = p
      const name = document.createElement('span'); name.className = 'tab-name'; name.textContent = p.split('/').pop()!
      const x = document.createElement('button'); x.textContent = '×'
      x.onclick = e => { e.stopPropagation(); void closeTab(p) }
      tab.onclick = () => { tabs.open(p); show(p); persist() }
      tab.append(name, x)
      return tab
    }))
    if (current && docs.get(current)?.lang === 'markdown') {
      const b = document.createElement('button'); b.className = 'tab-action'; b.textContent = previewOn ? '[ PREVIEW ✓ ]' : '[ PREVIEW ]'
      b.onclick = () => { setPreview(!previewOn); renderTabs() }
      bar.append(b)
    }
  }

  function renderStatus() {
    const s = $('.edit-status')
    if (!current) { s.textContent = 'NO FILE ─ pick one from the tree or Ctrl+Shift+P'; return }
    const head = view.state.selection.main.head
    const line = view.state.doc.lineAt(head)
    const d = docs.get(current)
    s.textContent = `${current}   Ln ${line.number}, Col ${head - line.from + 1}   ${d?.lang ?? 'text'}   ${d?.dirty ? '● MODIFIED' : ''}   ${statusMsg}`
  }

  function setPreview(on: boolean) {
    previewOn = on
    $('.edit-preview').classList.toggle('hidden', !on)
    if (on) void renderPreview()
  }
  function schedulePreview() {
    if (!previewOn) return
    clearTimeout(previewTimer)
    previewTimer = window.setTimeout(() => void renderPreview(), 200)
  }
  async function renderPreview() { $('.edit-preview').innerHTML = await renderMarkdown(view.state.doc.toString()) }
  $('.edit-preview').addEventListener('click', e => {
    const a = (e.target as HTMLElement).closest('a')
    if (!a) return
    e.preventDefault()
    if (/^https?:/.test(a.href)) void openUrl(a.href)
  })

  function persist() { win.setPersist({ files: [...tabs.paths], active: current } satisfies EditArgs) }

  async function handleArgs(a: EditArgs) {
    for (const f of a.files ?? []) await openPath(f, undefined, true)
    if (a.active && docs.has(a.active)) { tabs.open(a.active); show(a.active) }
    if (a.open) await openPath(a.open.path, a.open.line)
  }

  const offArgs = bus.on('edit:args', a => void handleArgs(a as EditArgs))
  const offWs = bus.on('workspace:changed', () => {
    current = null
    docs.clear()
    tabs.paths.splice(0)
    show(tabs.close(''))
    tree.reset()
    persist()
  })
  const offFs = bus.on('fs:changed', () => void tree.refresh())
  const offGuard = workspace.beforeChange(async () => dirtyCount() === 0 || confirmDialog({
    title: 'UNSAVED SHARDS', message: `${dirtyCount()} file(s) in EDIT have unsaved changes.\nSwitch workspace and discard them?`, ok: 'DISCARD', danger: true,
  }))
  const poll = window.setInterval(() => void checkExternal(), 3000)

  win.onFocus(() => { void checkExternal(); view.focus() })
  win.beforeClose(async () => dirtyCount() === 0 || confirmDialog({
    title: 'UNSAVED SHARDS', message: `${dirtyCount()} file(s) have unsaved changes.\nClose EDIT anyway?`, ok: 'DISCARD', danger: true,
  }))
  win.onClose(() => { offArgs(); offWs(); offFs(); offGuard(); clearInterval(poll); clearTimeout(previewTimer); view.destroy() })

  renderTabs(); renderStatus()
  void handleArgs(initial)
}
```

```ts
export function validName(raw: string): string | null {
  const name = raw.trim()
  if (!name || name.startsWith('/')) return null
  if (name.split('/').some(p => p === '..' || p === '.' || p === '')) return null
```

```ts
  const list = win.body.querySelector('.files-list') as HTMLElement
  const pathEl = win.body.querySelector('.files-path') as HTMLElement

  async function load() {
    pathEl.textContent = `${workspace.name()}/${cwd}`
    if (!workspace.root) { list.textContent = '  NO WORKSPACE ─ Ctrl+Alt+O'; entries = []; return }
    try { entries = await ipc.list(cwd) } catch (e) { list.textContent = `  ${String(e)}`; entries = []; return }
    sel = Math.min(sel, entries.length - 1)
    render()
  }

  function render() {
    list.replaceChildren(...entries.map((e, i) => {
      const row = document.createElement('div')
      row.className = 'files-row' + (e.is_dir ? ' dir' : '') + (i === sel ? ' sel' : '')
      const g = document.createElement('span'); g.className = 'g'; g.textContent = e.is_dir ? '[DIR]' : '[---]'
      const n = document.createElement('span'); n.className = 'name'; n.textContent = e.name
      row.append(g, n)
      row.onclick = () => { sel = i; render() }
      row.ondblclick = () => activate(e)
      return row
    }))
  }

  function cd(rel: string) { cwd = rel; sel = -1; win.setPersist({ cwd }); void load() }
  function activate(e: Entry) { if (e.is_dir) cd(e.path); else bus.emit('file:open', { path: e.path }) }
  const changed = (path: string) => bus.emit('fs:changed', path)

  async function act(a: string) {
    const cur = entries[sel]
    try {
      if (a === 'up') cd(parentOf(cwd))
      else if (a === 'refresh') await load()
      else if (a === 'file' || a === 'dir') {
        const raw = await promptDialog({ title: a === 'file' ? 'NEW FILE' : 'NEW DIRECTORY', message: `Name (inside /${cwd})` })
        if (raw === null) return
        const name = validName(raw)
        if (!name) { fault(`Invalid name: ${raw}`); return }
        const path = joinRel(cwd, name)
        if (await ipc.stat(path).then(() => true, () => false)) { fault(`${path} already exists`); return }
        if (a === 'file') { await ipc.write(path, ''); changed(path); bus.emit('file:open', { path }) }
        else { await ipc.mkdir(path); changed(path) }
      } else if (a === 'rename' && cur) {
        const raw = await promptDialog({ title: 'RENAME', message: cur.path, value: cur.name })
        if (raw === null) return
        const name = validName(raw)
        if (!name) { fault(`Invalid name: ${raw}`); return }
        await ipc.rename(cur.path, joinRel(cwd, name))
        changed(cur.path)
      } else if (a === 'delete' && cur) {
        const ok = await confirmDialog({ title: 'DELETE', message: `Permanently delete ${cur.path}${cur.is_dir ? ' and everything inside it' : ''}?`, ok: 'DELETE', danger: true })
        if (!ok) return
        await ipc.remove(cur.path)
        changed(cur.path)
      }
    } catch (e) { fault(e) }
  }

  win.body.querySelector('.files-bar')!.addEventListener('click', e => {
    const a = (e.target as HTMLElement).closest('button')?.dataset.act
    if (a) void act(a)
  })
  list.addEventListener('keydown', e => {
    if (e.key === 'ArrowDown') sel = Math.min(sel + 1, entries.length - 1)
    else if (e.key === 'ArrowUp') sel = Math.max(sel - 1, 0)
    else if (e.key === 'Enter' && entries[sel]) activate(entries[sel])
    else if (e.key === 'Backspace') cd(parentOf(cwd))
    else if (e.key === 'Delete') void act('delete')
    else if (e.key === 'F2') void act('rename')
    else return
    e.preventDefault()
    render()
  })

  const offFs = bus.on('fs:changed', () => void load())
  const offWs = bus.on('workspace:changed', () => cd(''))
  win.onFocus(() => list.focus())
  win.onClose(() => { offFs(); offWs() })
  void load()
}
```

```ts
function mountScan({ win, bus }: AppContext, args: ScanArgs) {
  let mode: 'files' | 'text' = args.mode ?? 'files'
  let rows: Row[] = []
  let sel = 0
  let fileCache: string[] | null = null
  let seq = 0
  let timer: number | undefined

  win.body.classList.add('scan')
  win.body.innerHTML = `<div class="scan-bar"><button class="scan-mode" data-mode="files">FILES</button><button class="scan-mode" data-mode="text">TEXT</button><input spellcheck="false" /></div><div class="scan-status"></div><div class="scan-list"></div>`
  const input = win.body.querySelector('input') as HTMLInputElement
  const status = win.body.querySelector('.scan-status') as HTMLElement
  const list = win.body.querySelector('.scan-list') as HTMLElement

  function setMode(m: 'files' | 'text') {
    mode = m
    win.body.querySelectorAll<HTMLElement>('.scan-mode').forEach(b => b.classList.toggle('active', b.dataset.mode === m))
    input.placeholder = m === 'files' ? 'fuzzy file name… (Tab: text search)' : 'search text in workspace… (Tab: files)'
    win.setTitle(m === 'files' ? 'SCAN ─ FILES' : 'SCAN ─ TEXT')
    win.setPersist({ mode } satisfies ScanArgs)
    schedule(0)
  }

  function schedule(ms = mode === 'files' ? 80 : 250) { clearTimeout(timer); timer = window.setTimeout(() => void run(), ms) }

  async function run() {
    const q = input.value
    const my = ++seq
    try {
      if (mode === 'files') {
        fileCache ??= await ipc.searchFiles()
        if (my !== seq) return
        rows = fuzzyFilter(fileCache, q, s => s, 200).map(path => ({ path }))
        status.textContent = `${rows.length} shown / ${fileCache.length} files${fileCache.length >= 20000 ? ' (index capped at 20000)' : ''}`
      } else if (q.trim().length < 2) {
        rows = []
        status.textContent = 'type 2+ characters'
      } else {
        status.textContent = 'scanning…'
        const hits: Hit[] = await ipc.searchText(q)
        if (my !== seq) return
        rows = hits
        status.textContent = `${hits.length} hits${hits.length >= 500 ? ' (capped at 500)' : ''}`
      }
    } catch (e) {
      if (my !== seq) return
      rows = []
      status.textContent = String(e)
      if (!String(e).includes('NO WORKSPACE')) fault(e)
    }
    sel = 0
    render()
  }

  function render() {
    list.replaceChildren(...rows.map((r, i) => {
      const row = document.createElement('div')
      row.className = 'scan-row' + (i === sel ? ' sel' : '')
      const loc = document.createElement('span'); loc.className = 'loc'
      loc.textContent = r.line ? `${r.path}:${r.line}` : r.path
      row.append(loc)
      if (r.text) row.append(document.createTextNode(r.text.trim()))
      row.onclick = () => pick(r)
      return row
    }))
    list.children[sel]?.scrollIntoView({ block: 'nearest' })
  }

  function pick(r: Row | undefined) { if (r) bus.emit('file:open', { path: r.path, line: r.line }) }

  input.addEventListener('input', () => schedule())
  input.addEventListener('keydown', e => {
    if (e.key === 'ArrowDown') sel = Math.min(sel + 1, rows.length - 1)
    else if (e.key === 'ArrowUp') sel = Math.max(sel - 1, 0)
    else if (e.key === 'Enter') { pick(rows[sel]); return }
    else if (e.key === 'Tab') setMode(mode === 'files' ? 'text' : 'files')
    else return
    e.preventDefault()
    render()
  })
  win.body.querySelector('.scan-bar')!.addEventListener('click', e => {
    const m = (e.target as HTMLElement).closest<HTMLElement>('.scan-mode')?.dataset.mode
    if (m === 'files' || m === 'text') { setMode(m); input.focus() }
  })

  const invalidate = () => { fileCache = null; schedule(0) }
  const offWs = bus.on('workspace:changed', invalidate)
  const offFs = bus.on('fs:changed', () => { fileCache = null })
  const offArgs = bus.on('scan:args', a => { setMode((a as ScanArgs)?.mode ?? mode); input.select(); input.focus() })
  win.onFocus(() => input.focus())
  win.onClose(() => { offWs(); offFs(); offArgs(); clearTimeout(timer) })

  setMode(mode)
  input.focus()
}
```

```ts
import { commands, type Command } from '../../kernel/commands'
import { fuzzyFilter } from '../../kernel/fuzzy'
import type { Registry } from '../../kernel/registry'
import type { AppManifest } from '../../kernel/types'

export interface Item { title: string; hint: string; glyph: string; run(): void }

export function buildItems(apps: AppManifest[], cmds: Command[], launch: (id: string) => void): Item[] {
  return [
    ...apps.filter(a => a.id !== 'sysop').map(a => ({ title: `Open ${a.name}`, hint: a.hotkey ?? '', glyph: a.glyph, run: () => launch(a.id) })),
    ...cmds.map(c => ({ title: c.title, hint: c.hint ?? '', glyph: '::', run: c.run })),
  ]
}

export function createSysop(registry: Registry): AppManifest {
  let el: HTMLElement | null = null
  const close = () => { el?.remove(); el = null }

  function openPalette() {
    const all = buildItems(registry.list(), commands.list(), id => void registry.launch(id))
    let shown = all
    let sel = 0
    el = document.createElement('div')
    el.className = 'sysop-backdrop'
    el.innerHTML = `<div class="sysop"><div class="sysop-prompt">SYSOP&gt;<input spellcheck="false" placeholder="program or command…" /></div><div class="sysop-list"></div></div>`
    const input = el.querySelector('input') as HTMLInputElement
    const list = el.querySelector('.sysop-list') as HTMLElement
    const exec = (it: Item | undefined) => { if (!it) return; close(); it.run() }
    const render = () => {
      list.replaceChildren(...shown.map((it, i) => {
        const row = document.createElement('div')
        row.className = 'sysop-row' + (i === sel ? ' sel' : '')
        const g = document.createElement('span'); g.className = 'glyph'; g.textContent = it.glyph
        const t = document.createElement('span'); t.textContent = it.title
        const h = document.createElement('span'); h.className = 'hint'; h.textContent = it.hint
        row.append(g, t, h)
        row.onclick = () => exec(it)
        return row
      }))
      list.children[sel]?.scrollIntoView({ block: 'nearest' })
    }
    input.addEventListener('input', () => { shown = fuzzyFilter(all, input.value, i => i.title, 50); sel = 0; render() })
    input.addEventListener('keydown', e => {
      if (e.key === 'ArrowDown') sel = Math.min(sel + 1, shown.length - 1)
      else if (e.key === 'ArrowUp') sel = Math.max(sel - 1, 0)
      else if (e.key === 'Enter') { exec(shown[sel]); return }
      else if (e.key === 'Escape') { close(); return }
      else return
      e.preventDefault()
      render()
    })
    el.addEventListener('pointerdown', e => { if (e.target === el) close() })
    document.body.append(el)
    render()
    input.focus()
  }

  return {
    id: 'sysop', name: 'SYSOP CMD', glyph: '>', category: 'system', multi: false, hotkey: 'Ctrl+Shift+K',
    run: () => (el ? close() : openPalette()),
  }
}
```
